# 4E4A1k3 watershed 3D viewer

Interactive 3D model of watershed 4E4A1k3 (2,363 ha, Pathardi and Ashti talukas, Maharashtra). Open `index.html` through GitHub Pages.

Controls: drag to rotate, right-drag to pan, wheel to zoom. "Walk mode" lets you walk over the terrain with the arrow keys.
